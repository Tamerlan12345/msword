# Nexus Logic Log

## 2026-02-25 — [Document Workflow] **Проблема:** Пользователи (Согласующие) не могли отклонить документ. В интерфейсе была только кнопка "Согласовать" (Forward), а в API отсутствовал метод `reject`. Это создавало логический тупик для некорректных документов. **Решение:** Добавлен эндпоинт `PUT /api/documents/:id/reject` в `documentController.ts` и кнопка "Отклонить" в `DocumentDetail.tsx`. Логика меняет статус документа и текущего согласующего на `REJECTED`. **Безопасность:** Использованы существующие статусы базы данных (`REJECTED`). Логика согласования (`forward`) не затронута. Тесты подтвердили, что только текущий согласующий может выполнить действие.
